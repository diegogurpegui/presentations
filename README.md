# Diego's Presentations

Slide decks published from `docs/`.

`docs/index.html` is the presentations page. Each talk lives in `docs/index/<slug>/` and is served at `.../index/<slug>`. A deck is one HTML file: styles, scripts, and fonts stay inside it, and images sit in `assets/` next to it.

See [AGENTS.md](AGENTS.md) for how to add a deck.
